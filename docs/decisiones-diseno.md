# Decisiones de diseño del dashboard de incidencias

Dashboard de gestión de incidencias

Estas son las decisiones de diseño tomadas en el proyecto. 

### **1\. Casi todo lo importante arriba del todo**

* Qué hicimos: Pusimos la barra de búsqueda, el botón de buscar, el filtro desplegable por estados y el botón de Nueva Incidencia en la parte de arriba.  
* Por qué: Ya que son las primeras acciones que se harán nada más abrir la app. Y dejamos el botón de nueva incidencia en verde para que destaque como la acción principal.

### **2\. La tabla como protagonista absoluta**

* Qué hicimos: Un tamaño correcto para las tablas de incidencias.  
* Por qué: Ya que se ve mejor visualmente cada información y ocupa un espacio suficiente.


### **3\. Separación de los contadores de incidencia**

* Qué hicimos:Se puso una línea en medio de cada contador de las incidencias  
* Por qué: Primeramente hicimos unos contadores para cada tipo de incidencia y que a su vez este esté dividido por una línea en el medio de cada una de ellas.

### **4\. Pantallas separadas** 

* Qué hicimos: Hicimos una pantalla para cada cosa en este caso para las nuevas incidencias y para  ver  los detalles.  
* Por qué:  para que todo esté separado y no se vea visualmente todo acoplado  y se vea más limpio.

### **5\. Mensaje con las acciones que se han hecho**

* Qué hicimos:Poner un recuadro abajo donde diga las acciones que se han hecho.  
* Por qué:  Para que cuando se realiza una acción ésta sea vista visualmente de manera más rápida, y se vea que se hayan hecho las acciones de manera correcta y si no es así se vea.
